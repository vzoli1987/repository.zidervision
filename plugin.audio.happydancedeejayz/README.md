# HappyDanceDeejayz Kodi addon

Kodi 21.3-kompatibilis audio plugin a [HappyDanceDeejayz.hu](https://www.happydancedeejayz.hu/) nyilvánosan elérhető mixeihez.

## Funkciók

- friss mixek RSS-feedből;
- kategóriák: Dance / Hands Up!, Trance, House, Egyéb és Promo;
- cím szerinti keresés;
- mixadatok és lejátszás Kodi audio playerrel;
- `script.module.resolveurl` integráció a támogatott átirányítások és hostok feloldásához.

## Telepítés

1. Kodi 21.3-ban válaszd az **Add-ons → Install from zip file** menüpontot.
2. Telepítsd a `plugin.audio.happydancedeejayz-1.0.0.zip` fájlt.
3. A Kodi telepített repositoryjából vagy ZIP-ből legyen elérhető a `script.module.resolveurl` legalább 5.1.0 verziója.
4. Indítsd el az addont a **Music → Add-ons** alatt.

Az addon kizárólag a weboldal nyilvánosan közzétett linkjeit használja. A tartalom jogszerű felhasználásáért és a szerzői jogi feltételek betartásáért a felhasználó felel.
