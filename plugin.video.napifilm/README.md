# NapiFilm Kodi-kiegészítő

Ez a kiegészítő Kodi 21.3 alatt a NapiFilm nyilvános katalógusát böngészi, és a filmoldalon található, engedélyezett lejátszóforrást próbálja ResolveURL segítségével lejátszani.

## Telepítés

1. Telepítsd a Kodihoz a `script.module.resolveurl` kiegészítőt egy megbízható, engedélyezett tárolóból.
2. A Kodiban válaszd a **Kiegészítők → Kiegészítőböngésző → Telepítés ZIP-fájlból** lehetőséget.
3. Válaszd ki a `plugin.video.napifilm-1.0.0.zip` fájlt.
4. Nyisd meg a **Videó-kiegészítők → NapiFilm** elemet.

## Megjegyzések

A kiegészítő nem tölt le tartalmat, és nem kerül meg DRM-et vagy hozzáférés-ellenőrzést. A lejátszás csak olyan videóforrásokkal használható, amelyekhez a felhasználónak és az üzemeltetőnek megfelelő joga van. A weboldal szerkezete később változhat, ezért a scraper időnként karbantartást igényelhet.

A beállításokban módosítható a weboldal alapcíme, ami teszt- vagy fejlesztői példány használatát is lehetővé teszi.
